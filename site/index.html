ARENA GRAPHICS

Mesin grafis broadcast MLBB local-first: delapan overlay HTML transparan 1920×1080, dikendalikan dari satu dashboard operator, siap dipasang di OBS Studio.

Overlay on-air

Semua overlay dirender pada kanvas 1920×1080 dengan latar transparan (alpha = 0), sehingga menyatu dengan gameplay di OBS. Tangkapan di bawah ditempel ke latar gelap agar terlihat jelas.

Dashboard operator

Satu tempat untuk mengatur turnamen, tim, pemain, draft, statistik, tema grafis, aset, dan koneksi OBS. State disiarkan realtime lewat Socket.IO.

Fitur

Dibangun untuk alur kerja satu operator, satu mesin, bind ke 127.0.0.1.

Manajemen turnamen

Turnamen, tim, pemain, match BO1/BO3/BO5, dan skor seri otomatis dari game yang selesai.

Grafis MLBB

Library hero, draft konfigurabel per game, statistik, dan MVP dengan KDA.

8 overlay siap siaran

Scoreboard, player intro, team intro, draft, statistics, MVP, fullscreen, dan objective alert — transparan 1920×1080.

Template Studio

Tema per grafis: warna, tipografi, skala, radius, accent bar. Tema aktif langsung on-air.

Asset Library

Upload logo tim, foto pemain, portrait hero, sponsor, dan background (maks 8 MB).

OBS Integration

Koneksi WebSocket, ganti scene, toggle visibility source — password tetap di server.

Cara pakai

Prasyarat: Node.js ≥ 22.12, pnpm ≥ 10, dan OBS Studio untuk siaran.

  1. Clone & setup

    Sekali jalan: cek toolchain, install dependency, buat .env, migrasi database.

    git clone https://github.com/zann06/arena-graphics.git
cd arena-graphics
pnpm setup        # tambahkan -Seed untuk data demo

  2. Jalankan

    Mode development menjalankan server :4000 dan dashboard :5173.

    pnpm dev

  3. Pasang overlay di OBS

    Tambah Browser Source, isi URL overlay, lalu set 1920×1080. Ulangi untuk tiap overlay yang dipakai. 

    http://127.0.0.1:4000/overlay/scoreboard
http://127.0.0.1:4000/overlay/draft
http://127.0.0.1:4000/overlay/mvp

  4. Mode produksi

    Build SPA disajikan oleh server API — satu origin melayani dashboard, REST, dan Socket.IO.

    pnpm build
node scripts/start-server.mjs
Integrasi OBS WebSocket sudah diuji terhadap mock obs-websocket, namun belum diverifikasi dengan instance OBS Studio nyata — konfirmasi ganti scene & visibility source sebelum siaran.
